# 🎯 Portfolio 1

A personal portfolio website built with HTML and CSS. Created to showcase projects and document learning journey through past work.

---

## 🎮 Preview

👉 [**Live Demo**](https://akshaypp-3.github.io/Learning-Projects/portfolio-1)

---

## ✨ Features
- 📌 Navigation sections (Home, About, Projects, Skills, Education, Contact)
- 🖼️ Clean and professional design
- 📱 Responsive layout
- 🔗 Links to GitHub, LinkedIn, and Email
- 🎨 Showcases past projects and technical skills

---

## 📋 Sections
- **Home** - Introduction and call-to-action
- **About** - Personal background and interests
- **Projects** - Showcase of completed work
- **Skills** - Technical expertise
- **Education** - Academic background
- **Contact** - Social links and contact information

---

## 🎓 Purpose
This portfolio is a personal project created to revise and document past learning and work experience. It serves as a reflection of skills developed throughout the learning journey.
