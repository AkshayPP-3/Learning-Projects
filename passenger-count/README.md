# 👥 Passenger Count

A simple and interactive passenger counter app built with HTML, CSS, and JavaScript. Perfect for tracking passenger entries and exits in real-time.

---

## 🎮 Preview

👉 [**Live Demo**](https://akshaypp-3.github.io/Learning-Projects/passenger-count)

---

## ✨ Features
- 🔢 Real-time passenger counting
- ➕ Quick increment button
- 💾 Save counts with timestamps
- 🎨 Clean and intuitive UI
- 📱 Works on desktop & mobile

---

## 📝 How to Use
1. Click **INCREMENT** to count each passenger 🚶
2. Click **SAVE** to record the count and reset counter 💾
3. View all saved counts in the history 📋
